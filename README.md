# # Employee Management System

A console-based Employee Management System developed in C.

## 📌 Project Overview

This project is a menu-driven application that allows users to manage employee records efficiently.

The system provides options to add, view, search, update, and delete employee records.

## 🚀 Features

- Add new employee records
- Display all employees
- Search employee by ID
- Update employee information
- Delete employee records
- Store employee data using file handling
- Menu-driven console interface

## 🛠️ Technologies Used

- C Programming
- Structures
- Functions
- File Handling
- Standard C Library

## 📋 Employee Information

Each employee record contains:

- Employee ID
- Name
- Age
- Department
- Designation
- Salary
